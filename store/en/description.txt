Day Showcase is the catalog app for Day, a framework for writing apps in Rust that draw with each platform's own native widgets.

The switch on the Controls page is a UISwitch on iPhone, a MaterialSwitch on Android, and an NSSwitch on a Mac. One Rust codebase draws all three. There is no web view in between, and nothing on screen is custom-drawn.

What's inside

• Controls — buttons, toggles, sliders, pickers, and text fields, each bound two ways to a signal
• Text and text areas — styling, selection, and editing
• Canvas & shapes — paths, gradients, transforms, and gestures
• Grid, List, Tabs, and Stack — the native layout and navigation containers
• Menus & dialogs, Toolbars, Preferences — the platform's own chrome
• Date & time, Localization, Resources — formatting and assets that follow the system
• Device & sensors — battery, connectivity, and live accelerometer, gyroscope, and magnetometer traces
• Platform services, Focus, Animation, Web View, Map, Refresh, and Crash reporting

Every screen is translated into English, French, Arabic, and Simplified Chinese. Switching language at runtime lays every screen out again, mirrored for Arabic.

Who it's for

Developers evaluating Day, and anyone curious what a Rust app looks like when it uses the platform's real widgets. Every screen works on first launch — no account, no network connection.

Day is open source. The code for every screen in this app is at github.com/daybrite/day.
