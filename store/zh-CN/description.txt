Day Showcase 是 Day 的演示应用。Day 是一个用 Rust 编写应用的框架，界面由各平台自己的工具包绘制。这个版本用 UIKit 绘制。同一份 Rust 代码在 Android 上用 Material 构建，在 macOS 上用 AppKit，在 Linux 上用 GTK 和 Qt，在 Windows 上用 XAML，在 HarmonyOS 上用 ArkUI，在浏览器里用 DOM。

应用共有 35 个页面，分为八组，每个页面都是框架某一部分的可操作演示。页面上的每个控件都绑定到一个值，下方的读数会随着你的操作而变化。

控件：按钮、开关、滑块、步进器、选择器、文本框、多行编辑器、日期和时间选择器、键盘焦点，以及指针光标。
布局：各种适配策略下的行、列和层，以及带跨格单元的网格。
导航与界面：推入式导航栈、标签页、菜单与对话框、窗口工具栏，以及在编辑器中打开每一项的内容列表。
数据：基于实时模型的列表和树，以及对本地存储的查询。
图形与媒体：画布上的形状、路径、渐变和变换，动画，Lottie 播放，内置资源，媒体播放，地图，以及网页视图。
平台：电池与网络连接，加速度计、陀螺仪和磁力计的读数，HTTP 请求，通知与应用角标，语音与触感反馈，以及文件。
应用与工具：本地化、脚本、微调、与 SwiftUI 的性能对比，以及崩溃报告。

每个页面的工具栏都有一个代码按钮，可在 GitHub 上打开该页面的 Rust 源码，让你对照结果阅读代码。星标按钮把页面固定到列表顶部，主题按钮切换外观。

应用已翻译成英语、法语、阿拉伯语和简体中文。在本地化页面切换语言会就地重建每个页面，阿拉伯语则镜像布局。每个页面首次启动即可离线使用。

Day 和这个应用都是开源的。框架位于 github.com/daybrite/day，应用源码位于 github.com/daybrite/Day-Showcase。
